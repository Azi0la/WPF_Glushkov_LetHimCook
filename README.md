# Платформа по обмену рецептами и кулинарным блогом
---
## Требования
---
* Windows, Visual Studio 2022 с компонентом разработки классических приложений .NET.
* .NET Framework 4.7.2, Entity Framework 6.2.
* SQL Server 2022 и SQL Server Management Studio.
* Установленный Microsoft Word для экспорта рецептов. PDF создаётся через Word.
---
## Запуск
---
1. В SSMS подключиться к своему SQL Server и выполнить db/lhc.sql. Скрипт создаёт новую БД LHC, существующую базу он не удаляет.
2. В WPF_Glushkov_LetHimCook/App.config заменить в строках connectionString значение data source в строке подключения на имя своего SQL Server.
3. Собрать решение и запустить приложение.

SQL-скрипт содержит иконки формата png, а также снимки рецептов и аватарки профилей. Пароли учётных записей хранятся как хэши. Самостоятельная регистрация создаёт только роль «Пользователь».

## Возможности и роли
---
Гость: Каталог, поиск, фильтры, сортировка, просмотр рецептов
Пользователь: Каталог, поиск, фильтры, сортировка, просмотр рецептов, создание рецептов, возможность социального взаимодействия с чужими рецептами
Модератор: Функции пользователя + возможность модерировать жалобы, а также самостоятельно удалять контент на площадке
Администратор: Модерация жалоб, управление ролями

Из готовых ролей на данный момент только гость и пользователь, остальные на стадии разработки

## Интерфейс
---
Боковое меню выезжает при наведении на левый край окна. Есть светлая и тёмная темы. Три неверные попытки ввести пароль включают капчу. Большая часть интерфейса гостям недоступна
